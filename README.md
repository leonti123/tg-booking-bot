# Telegram-бот записи на услуги (демо)

Демо-проект для портфолио: бот онлайн-записи для барбершопа, салона, мастера или студии.

## Возможности
**Для клиента**
- выбор услуги, дня и свободного времени кнопками
- занятые слоты не показываются, двойная запись невозможна
- имя и телефон, в том числе кнопкой «Отправить номер»
- `/my` — мои предстоящие записи

**Для администратора**
- мгновенное уведомление о новой записи
- `/today` — записи на сегодня
- `/export` — выгрузка всех записей в CSV (открывается в Excel)

## Стек
Python 3.10+, aiogram 3, SQLite, FSM-сценарии.

## Запуск
```bash
pip install -r requirements.txt
export BOT_TOKEN=токен_от_BotFather
export ADMIN_ID=ваш_telegram_id
python bot.py
```

Услуги, цены и часы работы настраиваются в начале `bot.py`.
